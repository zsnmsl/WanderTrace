# WanderTrace 2.4.3 — Pace preview and motion variation

## English

- Show live pace in minutes/seconds per kilometre beside the speed field. For example, **3 m/s → 5′33″/km**. Profile, speed, and randomization edits update the readout immediately.
- Show the reference pace range corresponding to the selected speed variation.
- Replace the repeating 640-second speed table with session-seeded, multiscale linear variation. Distance is integrated from the same curve; kilometre splits vary naturally rather than being forced to differ.
- Default new configurations to **10% speed variation**. Existing saved **0%** values keep constant-speed behavior; the selectable range remains **0–50%**.
- Replace four-second straight-line GPS offsets with correlated slow drift and smaller short-term variation, smoothly interpolated within the configured **1–3 metre radius**.
- Keep zero-start-time route previews at the starting point and include the session seed in braking-cache identity.
- Include daily commit tooling, an owner-operated release publishing script, version-specific release notes, and workflow documentation.

Validation during development: **66 Android unit tests passed**, standalone route-engine checks passed, and Lint reported no errors. Pace UI updates, speed/distance consistency, varied kilometre splits, constant-speed compatibility, and drift bounds/continuity were checked locally. GPS behavior and 云运动 compatibility were **not physically verified** for this revision; the drift is a synthetic model, not a calibrated receiver model.

The native library is **byte-identical to 2.4.2**. This release does not remove 2.4.2's native loading conditions or existing sensor coverage limitations. Stop simulation before updating and start a new route afterward so an active trajectory is not reinterpreted midway through the new motion model.

The APK is a non-debuggable Release build signed with the project's existing **local development certificate**. Package: `com.wandertrace`; versionCode: `13`; versionName: `2.4.3-pace`.

## 简体中文

- 速度输入旁实时显示**分 / 公里配速**，例如 **3 m/s 对应 5分33秒 / 公里**；修改速度、出行预设或随机幅度会同步更新。
- 显示所选速度随机幅度对应的参考配速范围。
- 移除固定 640 秒重复速度表，改为按本次运行生成的多时间尺度线性变化；距离按同一速度曲线积分，公里配速自然浮动，不强制每公里都不同。
- 新配置默认 **10%** 速度随机，已有路线保存的 **0%** 仍代表匀速，可选范围仍为 **0–50%**。
- GPS 偏移改为慢漂移叠加小幅短期变化，在设定的 **1–3 米半径**内平滑过渡。
- 未设置开始时间的路线预览保持在起点，刹停缓存按本次运行区分。
- 补充日常提交脚本、一键发布脚本、分版本更新说明及使用文档。

开发阶段通过 **66 项 Android 单元测试**和独立路线引擎检查，Lint 无错误；检查覆盖配速联动、速度与距离积分、公里用时变化、匀速兼容及漂移边界 / 连续性。**尚未进行 GPS 效果或云运动兼容性的真机验证**；GPS 漂移属于合成模型。

原生库与 **2.4.2 完全一致**，不改变上一版原生库的加载条件及传感器覆盖限制。建议升级前停止模拟，安装后重新开始路线，避免运行中的轨迹因模型变化而发生跳变。

安装包为不可调试的 Release 构建，沿用项目现有的**本地开发证书**签名。包名 `com.wandertrace`，版本号 13，版本名称 `2.4.3-pace`。
