# WanderTrace 2.4.2 — Step timing and delivery fixes

## English

- Fix undercounting after scheduler delays: integrate the full elapsed interval instead of truncating it to one second.
- Calculate an individual timestamp for each generated step, including reconstructed events after a delay.
- Retain events during temporary socket congestion and retry on later updates, even if no new step is generated. Delivery queues are bounded; overflow is counted explicitly.
- Show captured sensor channels, sent/pending events, retries, drops, and whether the corrected native implementation is loaded.
- Add portable timing/queue checks and Android socket regression checks.

Validation during development: **56 Android unit tests passed**, portable native timing/queue checks passed, and Android native components compiled successfully. Android socket checks and 云运动 on PLQ110 were **not run on a physical device** for this revision. Wake-up sensors, pre-existing subscriptions, vendor health APIs, and accelerometer-derived steps remain coverage limitations.

**Loading requirement:** this version changes the native library. Covering an existing installation or hot-reloading Java does not replace an already resident old native bridge. The system framework process must load the new library in a fresh process lifetime. The app does not restart the system automatically.

The APK is a non-debuggable Release build signed with the project's existing **local development certificate**, not a separately managed production signing certificate. Package: `com.wandertrace`; versionCode: `12`; versionName: `2.4.2-stepfix`.

## 简体中文

- 修复线程调度延迟后只累计 1 秒、导致步数偏少的问题。
- 为每一步计算独立时间戳，补发时不再全部使用同一时刻。
- 通道暂时拥堵时保留事件，并在后续更新重试；队列有容量上限，溢出丢弃会明确计数。
- 状态详情增加订阅通道、已发送 / 待发送事件、重试、丢弃数量及原生补丁加载状态。
- 增加可在本机运行的计时 / 队列检查，以及 Android Socket 回归检查。

开发阶段通过 **56 项 Android 单元测试**和本机原生逻辑检查，Android 原生组件编译成功。本版没有完成 Android Socket 检查或云运动 / PLQ110 的真机验证；唤醒型传感器、Hook 安装前已存在的订阅、厂商健康接口和通过加速度计自行计算步数的路径仍存在覆盖限制。

**生效条件：本版修改了原生库，覆盖安装或 Java 热重载不能替换已驻留的旧原生桥，需系统框架进程在新的生命周期加载。应用不会自动重启系统。**

安装包为不可调试的 Release 构建，沿用项目现有的**本地开发证书**签名。包名 `com.wandertrace`，版本号 12，版本名称 `2.4.2-stepfix`。
